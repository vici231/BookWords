# 知乎英语日报提示词总纲

本项目运行时使用 `base_system_prompt.txt` 与 `story_prompt.txt`。本文件只保留给编辑和维护者阅读，不单独参与模型调用，避免形成第二套事实来源。

## 产品目标
学习者选择 3–30 个目标词，编辑器从知乎公开问答、知识文章或热榜提炼一个日常问题，写成一篇短小、可核验、适合学习的英语日报。目标词是普通词汇，不是人物、地点、品牌、组织或道具名称。

## 生成顺序
1. 读取每张卡的 `word`、`pos`、释义和例句，先确认目标词的词性与常见句法位置。
2. 先搭建事件线：现场开场 → 传闻/调查 → 小转折 → 轻巧收束。
3. 将语义或词性互相支撑的目标词放在同句或同段；无法自然共现的词放在相邻句中，用因果、转折或观察视角连接。
4. 英文与中文逐段对应，英文长度遵循 `params.length`，所有目标词原形都用 `**word**` 标记。
5. 最后检查标题、每个目标词的词性、免责声明与安全限制，再输出严格 JSON。

## 禁止事项
- 禁止“目标词首字母 · 目标词首字母”的标题。
- 禁止一词一句的流水账、反复使用同一个空泛句型、把词当专有名词、或为了凑长度重复塞词。
- 禁止 NSFW、中国相关内容、现实人物/品牌/国家/新闻和可能造成现实误导的指控。

## 输出结构
```json
{
  "story": {
    "publication": "知乎英语日报 · Zhihu English Daily",
    "genre": "gossip|odd-fact|fictional-breaking",
    "dateline": "知乎英语日报 · Learning Edition",
    "title": "吸睛且自然的英文标题",
    "en": "分段英文刊物",
    "cn": "逐段对应的中文刊物",
    "hooks": ["目标词与画面/动作/因果的简短记忆提示"],
    "disclaimer": "本文为基于知乎公开内容生成的英语学习材料；已进行摘要与改写，不替代原文。"
  }
}
```

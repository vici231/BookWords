# 提示词工程说明

本目录存放「刊见单词」的运行时提示词。当前模式把目标词与知乎公开内容组合成日常科普、冷知识或轻娱乐英语日报。核心思想是：**先回答一个清晰问题，再让目标词自然参与解释**，而不是机械造句或套用虚构杂志背景。

## 文件

| 文件 | 用途 |
| :--- | :--- |
| `master_prompt.txt` | 维护总纲：记录运行时提示词的生成顺序与禁止事项，不单独参与调用 |
| `base_system_prompt.txt` | 基础 System Prompt（记忆教练人格）——所有模式共享 |
| `story_prompt.txt` | 知乎英语日报生成规则、栏目类型、目标词用法、改写与安全边界 |

> 说明：当前运行时使用 `base_system_prompt.txt + story_prompt.txt`，用户消息携带 `{mode, level, params, cards}`；master 仅供维护者对照。

## 关键设计原则

1. **认知科学挂钩**：间隔重复、生动性加工（bizarreness）、双重编码（语言+画面）、难度适配。
2. **自然用词**：目标词是普通词汇，按其词性在句子里自然使用；文章围绕一个 What / Why / How 问题展开。
3. **难度可选**：`level`（junior 初中 / senior 高中 / cet 四六级）控制故事里**目标词之外**词汇的难度。
4. **结构化输出**：始终输出 JSON，前端零解析成本。
5. **真实失败**：无 AI Key 或上游失败时返回可解释错误，不伪造知乎内容或 AI 结果。
6. **来源边界**：知乎内容只作为事实线索；需要摘要、重组和署名，禁止逐句翻译、冒充原作者或伪造数据。

## 调用方式

后端把持 `prompt_templates.py`，把用户拖入的单词卡 JSON 注入模板，构造：

```
[base_system_prompt] + [story_prompt] + 具体的卡牌数据
```

然后调用 OpenAI 兼容端点。返回的 JSON 结构（见各 Prompt 的严格 JSON 段）会经过后端结构与安全校验，再交给前端渲染。

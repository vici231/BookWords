ABOUT THIS PROJECT · 关于本项目

刊见单词 Bookwords

把生词放进知乎知识的日常问题——生成一篇双语英语日报，再用练习把它们留在脑海里。

AI 生成双语日报 知乎开放平台 · 黑客松 本地优先 · 数据不离开设备

它如何工作

一条从「生词」到「记住」的完整流水线

  1. 1
    收集在搜索词库找到要记的词，收藏进单词本
  2. 2
    选题选择原创灵感，或从知乎热榜、故事、知识与回答中挑选素材
  3. 3
    出版AI 把目标词写进一篇 Zhihu 双语日报（英文正文 + 中文对照 + 记忆口诀）
  4. 4
    阅读与练习翻书阅读日报，用填空练习把目标词填回故事

AI WRITING

外部 AI → 双语日报

使用设置页配置的 OpenAI 兼容接口生成双语学习文章；输出异常时自动校验纠正，不生成占位内容。

CREDIT

版权署名

每篇内容都以中文小字标注来源；使用知乎素材时同时保留标题、作者与赞同数。

QUOTA GUARD

额度保护

搜索与热榜使用持久缓存；合格的生成文章短时缓存，减少外部 API 的重复调用与成本。

技术栈

Flask · Python 原生 HTML / CSS / JS OpenAI 兼容生成 API 知乎开放平台 API 本地加密账户

说明与免责声明

所有日报均为 AI 生成的英语学习材料，并非真实新闻；改编自知乎的内容均已署名原作者，仅用于学习练习。

刊见单词 · 记忆学习工具；本期 知乎英语日报为模仿真实报刊排版的学习练习素材，不构成真实新闻或建议。

文章生成 API

支持 DeepSeek、OpenAI 与其他 OpenAI 兼容接口。API Key 仅保存在本机后端，不会写入网页或日志。

仅用于知乎搜索、热榜等文章选材；知乎直答生成暂未启用。Secret 只保存在本机 backend/settings.json。

视觉风格

移动端布局预览测试阶段使用，在桌面浏览器中强制显示移动端下栏

数据与缓存

AI 配置（含 API Key）只保存在本机 backend/settings.json；账户数据保存在加密的 backend/data/users.json，已列入 .gitignore，不会随 GitHub 上传。若仍不放心，可一键清除。
